## 三、学习场景的用量估算

以 P1 `llm-gateway` 阶段的典型强度为例：

**假设**：每天 200 次调用（调试 + 测试），平均输入 1500 token（含 system prompt），平均输出 400 token。

| 项 | 计算 | 结果 |
|---|---|---|
| 日调用 | — | 200 次 |
| 月输入 | 200 × 1500 × 30 | 9 M token |
| 月输出 | 200 × 400 × 30 | 2.4 M token |

**各方案月成本对比：**

| 方案 | 月成本 | 是否在预算内 |
|---|---|---|
| `glm-4.7-flash`（全免费） | **¥0** | ✅ |
| `qwen-plus` | 9×0.8 + 2.4×2 = **¥12.0** | ✅ |
| `deepseek-flash`（非峰时） | 9×1.1 + 2.4×4.3 = **¥20.2** | ✅ |
| `deepseek-v4-pro`（非峰时） | 9×4.8 + 2.4×14.3 = **¥77.5** | ⚠️ 接近上限 |
| `glm-5.3` | 9×8 + 2.4×28 = **¥139** | ❌ 超标 |

**结论**：**日常用 `glm-4.7-flash`（免费）+ `qwen-plus`（约 ¥12/月）**，
质量敏感的关键实验才切 `deepseek-flash`。**旗舰模型（`glm-5.3` / `deepseek-v4-pro`）只做偶发对照，不做日常主力。**

## 四、五个降本手段（按性价比排序）

### 1. 关掉思考模式 —— 最容易被忽略的一条

DeepSeek V4 **默认开着思考模式**，而思考 token 也计费。

实测（见 `experiments/w1-05-httpx/04_thinking_control.py`）：

| 模式 | 平均耗时 | 输出 token | 其中思考 | 成本 |
|---|---|---|---|---|
| 思考开启（默认） | 2.82 s | 1076 | **1041（97%）** | ¥0.004835 |
| 思考关闭 | **1.28 s** | **103** | 0 | **¥0.000565** |

**差 8.6 倍。** 最极端的例子：一道「设计重试策略」的题，开着思考花了
¥0.003945 但**正文一个字都没输出**（900 token 全被思考吃光）；
关掉思考只花 ¥0.000377，拿到 102 字的完整答案。

- **关法**：请求体顶层加 `{"thinking": {"type": "disabled"}}`
- **判据**：这个任务，一个熟练的人**需要停下来想一下**吗？
  不需要 → 关掉；需要 → 开着，或用 `reasoning_effort="low"`
- ⚠️ 顺带一个坑：思考模式下 `temperature` / `top_p` / `presence_penalty` /
  `frequency_penalty` **全部无效**（官方说明：不报错，也不生效）

> 💡 还有个连带好处：关掉思考后，同样的 `max_tokens` 能写出更多正文。
> 思考 token 是在**挤占正文预算**，不只是多花钱的问题 ——
> 实测 `max_tokens=64` 时，开着思考会截断、关掉就能拿到完整答案。

### 2. 缓存命中价 —— 最狠的一招

重复的前缀（尤其**固定的 system prompt**）命中缓存后，输入价格降到 **1/50 ~ 1/100**。

- 做法：**把 system prompt 写得长而稳定**，不要每次动态拼接
- 效果：输入侧成本可降 80%+
- 三家都支持，多数是自动生效（隐式缓存）

### 3. 优先打免费模型

`glm-4.7-flash` 完全免费。调试链路、验证接口连通性、跑回归测试，**一律先用它**。

### 4. Batch API 半价

离线、不要求实时返回的任务（数据清洗、批量标注、批量评测），走 Batch 接口**一律五折**。

### 5. 避开峰时

DeepSeek 峰时（**北京时间 09:00–12:00 / 14:00–18:00**）价格翻倍。
跑压力测试、批量任务尽量安排在晚上或周末。

## 六、保护措施（防止意外烧钱）

| 风险 | 措施 |
|---|---|
| 死循环狂发请求 | 代码里写**最大重试次数**和**单次请求超时**（P1 就会实现） |
| 忘记关掉的压测脚本 | 给客户端设**月度硬上限**，接近就抛异常 |
| Key 泄露被盗刷 | Key 只放 `.env`；**绝不提交 git**；怀疑泄露立刻去控制台重置 |
| 程序无限重试 | 限流 + 指数退避，别用 `while True` 裸重试 |

`.env.example` 里的 `MONTHLY_BUDGET_CNY=100` 就是给程序读的**预算上限**，
P1 网关会实现「累计成本超限即拒绝请求」的逻辑。
